## Reporting a vulnerability

Please do not open a public issue for a vulnerability.

If this repository is public on GitHub, use private vulnerability reporting: open the **Security** tab, choose **Report a vulnerability** and describe the problem. The repository owner has to switch the feature on in the repository settings first, and it exists for public repositories only.

If the repository is private or hosted elsewhere, write to: <fill: a contact address or private channel>.

## Supported versions

Security fixes go to the latest release, or to the default branch if there are no releases. Older versions are not patched unless this section says so.

## What to expect

A report is acknowledged, and the reporter is told whether it is treated as a vulnerability. A fix is released before the details are published, and the date is agreed with the reporter. This policy promises no response time; add one only if you can keep it.
