# docs/user/

For the people who use what this project builds, not the people who build it. Empty until there is something to use: delete this folder if the project has no end users, or fill it as the first user-facing feature ships.

It takes the same four kinds as `docs/dev/` (`tutorials/`, `how-to/`, `reference/`, `explanation/`). Create the first page with `python3 tools/new_doc.py how-to "Title" --audience user`, which also creates the folder. Then set `status: active` here.
