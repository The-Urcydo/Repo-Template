# docs/dev/tutorials/

Learning-oriented. A tutorial takes a newcomer by the hand to a working result. It never digresses into explanation (link to `explanation/`) and never lists options (that is `reference/`). Every step must succeed every time; if a tutorial breaks, fix or delete it.

Add one with `python3 tools/new_doc.py tutorial "Title"`.
