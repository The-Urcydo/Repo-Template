# docs/dev/

For contributors, human or agent: how this repo works and how to change it. One folder per kind of need.

| Folder | Reader's need |
|---|---|
| `tutorials/` | "Teach me": learn by doing |
| `how-to/` | "Help me do X" |
| `reference/` | "What exactly is Y?" |
| `explanation/` | "Why is it this way?" |

Docs for the end users of what you build go in `docs/user/`. Decisions, which every audience reads, are in `docs/decisions/`.
