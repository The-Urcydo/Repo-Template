# docs/dev/how-to/

Goal-oriented. A how-to starts from a goal ("cut a module"), lists the steps, and stops. It does not teach concepts (link to `explanation/`) or enumerate every option (link to `reference/`). Name pages by the task: `cut-a-module.md`, not `modules.md`.

Add one with `python3 tools/new_doc.py how-to "Title"`.
