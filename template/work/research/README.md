# work/research/

Working space for the researcher: source excerpts, comparisons, long notes. Conclusions for a specific item go in that item's `research.md`. When a finding must outlive the item, the scribe promotes it into `docs/` (explanation or reference) and the raw note is deleted here. Keep each note dated and sourced.
