# work/inbox/

Drop anything here: a request, an idea, a bug report, a link. One note per file, any format, any name (for example `2026-11-01-export-to-csv.md`). The orchestrator reads the inbox, turns actionable notes into items with `python3 tools/new_item.py`, then deletes the note. Nothing stays here long.
